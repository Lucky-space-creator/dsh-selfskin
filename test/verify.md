# 验收清单（真机）

自动化测试覆盖的是**装配与逻辑**，不覆盖**观感**。以下每一项都需要在运行中的应用里目视确认。

测试现状：`node test/pure.test.mjs`（29 项）+ `node test/client-harness.mjs`（30 项）+ `node test/validate-package.mjs`（8 项）= 67 项全绿。
它们能证明：皮肤按官方契约注册、令牌覆盖层形状正确、插槽被正确占用、样式表随开关正确组装、
开关的 on-state 选择器挂在正确的元素上、涟漪在点击时进入插件自有图层且未触碰宿主元素、
侧边栏行的 id 与面板的 key 一致、壁纸归属皮肤分区。
它们**不能**证明页面看起来对不对。

---

## 0. 前置

```powershell
node build.mjs                       # 确认产物是最新的
E:\AI_Pro\dsh-skin\test\install.ps1  # 应用必须先关闭
# 重启应用
```

> `file:` 前缀不能省。裸路径会被 pnpm 解析成 `link:`（跨盘符号链接），而它会**静默失败** ——
> 依赖写进清单、`node_modules` 却是空的。安装助手已经替你处理了这点。
> 改过 `src/` 之后必须重新构建再装，且普通 `add` 会被 pnpm 短路（报 Already up to date），
> 只有 `install.ps1 -Refresh`（内部是 remove + add）才会真正替换拷贝。

**验收基线**：安装结果以 `dsh plugin add` 的返回、以及侧边栏出现的「皮肤管理」入口为准 ——
不要用日志或进程列表推断是否生效。

## 1. 挂载与入口（1.1.0 改动点）

- [ ] **侧边栏出现「皮肤管理」一行**，带调色板图标，位于宿主「插件」「任务」之后。
- [ ] 点击该行 → **内容区切到插件面板**，侧边栏该行高亮、图标呈填充态。
- [ ] 面板顶部有「皮肤管理」标题与说明；下面依次是皮肤行（含壁纸）、按钮特效、氛围特效。
- [ ] 侧边栏**收起**时只显示图标，展开时显示「皮肤管理」文字；图标在两种尺寸下都清晰。
- [ ] 点击宿主其它面板项（会话、插件、任务）→ 能正常切走，再点「皮肤管理」能切回。
- [ ] **通用设置 → 常规里不应再出现**皮肤 / 按钮特效 / 氛围特效三行
      （这是需求 ② 的判据：插件不再是设置里的一行，而是独立入口）。
- [ ] 控制台无 `slot entry crashed in ...`；无 `theme "xxx" is not registered`。

## 2. 皮肤

- [ ] 选择器按三组显示：**宿主外观 / 内置皮肤 / 已导入**。
- [ ] 5 套内置皮肤逐一切换：主画布、侧栏、卡片、输入框、按钮底色**全部**跟着变。
- [ ] 切到 `selfskin-ocean` 后按 F5 刷新 —— 皮肤**保持**（证明 localStorage 回填生效）。
- [ ] 切回「亮色（宿主）」/「暗色（宿主）」/「跟随系统」—— **能真正回到宿主外观**
      （这是早期版本的缺陷点：错误的 sentinel id 会让 `setTheme` 静默失败）。
- [ ] 在官方「外观」行把主题改成亮色 → 皮肤选择器自动跳到「亮色（宿主）」，不残留旧皮肤名。
- [ ] 浅色皮肤（樱花 / 暖纸）下：正文、代码块、消息气泡**对比度足够**，无白底白字。
- [ ] 深色皮肤（子夜）下：`--dsw-alias-label-*` 层级仍可辨（标题 > 正文 > 次要）。

### 2b. 壁纸（1.1.0 从氛围特效搬到这里）

- [ ] 皮肤行下方有「壁纸」子行，带独立开关（**与皮肤选择器同一分区**）。
- [ ] 「氛围特效」行里**没有**壁纸开关（只有极光 / 光尘 / 毛玻璃）。
- [ ] 「壁纸」开 → 展开面板：图片网址、选择本地图片、清除图片、不透明度、模糊、显示方式。
- [ ] 粘贴图片网址 → 壁纸出现在内容**之下**，卡片与输入框仍不透明、文字可读。
- [ ] 调整不透明度 / 模糊滑块，实时生效且**不卡顿**（rAF 未堆积）。
- [ ] 铺贴方式四种（填充/适应/拉伸/平铺）表现各不相同且无错位。
- [ ] 「选择本地图片」选一张 < 2.5 MB 的图 → 生效；选一张超大的 → 给出提示而非静默失败。
- [ ] 「清除图片」→ 壁纸撤掉，但开关仍保持"开"（令牌覆盖层正确撤回）。
- [ ] 关掉壁纸开关 → 面板收起，且 `body::before` 上的样式被撤掉（DevTools 检查）。

## 3. 自定义导入

- [ ] 点「填入模板」→「导入」→ 选择器出现「已导入」分组且皮肤立即生效。
- [ ] 粘贴 `{"colorScheme":"dark","tokens":{"background":"#000"}}` → 报错并**指出键名**
      （必须以 `--dsw-` 开头）。
- [ ] 粘贴近乎乱码的 JSON → 报 JSON 解析失败，界面不崩。
- [ ] 重复导入同一份文档 → 提示已导入，不产生第二条。
- [ ] 选中导入皮肤后点「删除」→ 回到宿主外观，样式无残留。
- [ ] 刷新页面后导入的皮肤仍在。

## 4. 按钮特效

- [ ] 「抬升与辉光」开：悬停按钮有轻微上浮 + 品牌色辉光；按下有回弹。
- [ ] 「流光」开：主按钮悬停时有渐变滑动感；**纯色按钮不应出现异常拉伸**。
- [ ] 「涟漪」开：点击按钮出现从指针位置扩散的圆形涟漪，**且被限制在按钮圆角内**
      （不溢出到按钮之外）。
- [ ] 「涟漪」关：点击**完全没有**涟漪。
- [ ] 涟漪开关切换后无需刷新即生效。
- [ ] 系统开启「减弱动态效果」后：涟漪与流光不播放（媒体查询生效）。
- [ ] 键盘 Tab 聚焦按钮有可见焦点环。

## 5. 氛围特效

- [ ] 「极光」开：内容**后面**出现缓慢流动的彩色光晕；切换皮肤后光晕**随之换色**。
- [ ] 「光尘」开：界面之上有稀疏低透明度浮尘，**不遮挡点击**（能正常点中下层按钮）。
- [ ] 「毛玻璃」开：画布/侧栏更透，卡片与输入框仍不透明、文字可读。
- [ ] 三个开关两两叠加（极光+毛玻璃、毛玻璃+光尘）无互相破坏。
- [ ] 关闭全部氛围特效后：`body::after` 上的极光样式被撤掉（DevTools 检查）。
- [ ] 壁纸相关见 §2b —— 它已不属于这一行。

## 6. 互不干扰

- [ ] 官方「外观」行仍可正常使用，与本插件互不打架。
- [ ] 其他已装插件（`dsh-boot-animation`、`dsh-our-free-model`）行为不变。
- [ ] 切换会话 / 打开关闭侧栏 / 打开设置再关闭 —— 无样式错乱、无重复注入的 `<style>`。

## 7. 卸载

- [ ] `dsh plugin --profile desktop remove dsh-selfskin` + 重启后：
      - 侧边栏的「皮肤管理」一行消失；
      - `<head>` 里不再有 `data-plugin="dsh-selfskin"` 的 `<style>`；
      - `body` 上的行内 `--dsw-*` 自定义属性被回退到宿主默认值；
      - `body::before` / `body::after` 不再有插件样式；
      - 界面回到宿主原样。

## 8. 开关控件（1.0.2 有效性 + 1.0.3 宿主对齐）

这一节复验的是"点了开关没反应"那个缺陷。**开关的图形必须随点击立即变化** ——
这是判断修复是否生效的唯一标准，不要只看滑块下面的面板有没有展开。

- [ ] 点「壁纸」开关（现在在**皮肤行**里）：**胶囊底色立刻变成品牌色、圆形滑块滑到右侧**（壁纸面板同时展开）。
- [ ] 再点一次：胶囊回到中性灰、滑块滑回左侧（面板收起）。
- [ ] 「极光 / 光尘 / 毛玻璃」三个开关同样有上述变化（它们和「壁纸」是同一个控件）。
- [ ] 「按钮特效」分区的「抬升与辉光 / 流光 / 涟漪」三个开关同样有变化。
- [ ] 刷新页面后，**上次开着的开关是以"开"的样子出现**的（不是全灰）。
- [ ] 切到别的面板再切回「皮肤管理」，状态仍然正确。

**1.0.3：与宿主开关并排比对**（把宿主自己的开关和我们的开关放进同一屏看）

- [ ] **尺寸一致**：胶囊 36×20，滑块 16×16 正圆，滑块四周留白 2px。
- [ ] **形状一致**：胶囊是**圆头**、滑块是**正圆**；不应出现"方头胶囊"或"方块状滑块"
      （那是全局超椭圆样式没被退出的表现）。
- [ ] **关态配色一致**：都是中性灰胶囊 + 白滑块在左 —— 不是"我们的更浅/更深"。
- [ ] **开态配色一致**：都是同一个品牌色，滑块都在右端、位置贴合。
- [ ] **动效一致**：底色**瞬切**、只有滑块滑动（宿主就是这样；这不是卡顿）。
- [ ] **无悬停变色**：鼠标悬停时胶囊不变色、不变形，只有光标变成手型（宿主没有 hover 态）。
- [ ] 键盘 Tab 聚焦开关时有可见焦点环，偏移量与宿主一致。

**其余**

- [ ] 开着「壁纸」时点「选择本地图片」：能弹出文件选择框；选一张 < 2.5 MB 的图能生效。
- [ ] 开着「壁纸」时点「清除图片」：图片被撤掉，开关仍保持"开"。
- [ ] 用读屏或浏览器无障碍面板检查任一开关：名字应念一次（如"涟漪"），
      **不应重复念两遍**（可见文字已标记为装饰，名字由 `aria-label` 提供）。
